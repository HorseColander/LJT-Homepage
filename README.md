# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Content

* `_pages/about.md` — the about/home page with personal details, education, research experience, publications, skills, and contact information.
* `_pages/publications.html` — the publications list page.
* `_publications/` — individual publication entries.
* `_config.yml` — site-wide configuration.
* `_data/navigation.yml` — top navigation menu.

## Local development

```bash
bundle install
bundle exec jekyll serve
```
